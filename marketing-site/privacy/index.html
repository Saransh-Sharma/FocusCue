Privacy Policy

FocusCue is local-first by design.

FocusCue is a macOS teleprompter workspace designed to keep your scripts, playback, and delivery tools under your control. This policy covers how the app handles content, optional cloud features, and support requests.

1. Plain-language summary

FocusCue stores scripts locally on your Mac unless you choose to export them. Core teleprompter workflows do not require an account, and the public marketing website does not require login.

2. Data handling disclosures

  • Script text is stored locally on-device.
  • Voice data is used for speech-aware prompting and is not stored as raw recordings by default.
  • Transcripts are not stored unless you explicitly save or export content.
  • API keys used for optional integrations are stored locally in Keychain.
  • Browser remote output runs on your local network for companion viewing.

3. Optional cloud features

If you enable optional cloud speech or AI features, only the limited data required for that selected feature may be processed by the provider you choose. These services are opt-in and are not required for basic app use.

4. Analytics

Analytics are off by default. If the product’s analytics posture changes in the future, this page should be updated before release so the public statement remains accurate.

5. Privacy questions

For privacy questions or product support, contact support@focuscue.app.
